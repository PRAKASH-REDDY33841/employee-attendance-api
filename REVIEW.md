## Examined and Decided NOT a Defect

1. **`IST = timezone(timedelta(hours=5, minutes=30))`**:
   - We verified that Indian Standard Time (IST) has a constant offset of UTC+05:30 with no daylight saving time (DST) adjustments. Defining a fixed `timezone(timedelta(hours=5, minutes=30))` is exact and performs faster than importing heavier timezone libraries.
2. **Environment variable configuration fallback**:
   - `os.getenv("MONGO_URI", "mongodb://localhost:27017")` and `os.getenv("MONGO_DB", "attendance_db")` correctly prioritize system environment variables while falling back to sensible local defaults or `.env` file values, fulfilling the environment contract.
3. **Absence of internal `_id` in response payloads**:
   - Stripping `_id` from responses is strictly compliant with the contract: `_id` is an internal MongoDB implementation detail and must never appear in API responses or request bodies.
